# Ergebnisse der Messübung

Hier liegen die Archivdateien der Seminare (`seminar-JJJJ-MM-TT.json`) für die
[Langzeitauswertung](https://mcweizen70.github.io/TS32/langzeit.html).

- Archivdatei in der [Auswertung](https://mcweizen70.github.io/TS32/auswertung.html) erzeugen
  (Abschnitt „Seminar für die Langzeitauswertung archivieren“).
- Hochladen: in diesem Ordner auf „Add file → Upload files“, Datei hineinziehen, „Commit changes“.
- Zwei Seminare am selben Tag: zweite Datei umbenennen, z. B. `seminar-2026-10-17-2.json`.

Die Dateien enthalten nur Gruppennummern und Messwerte – keine Namen oder anderen
personenbezogenen Daten. Das Repo ist öffentlich.
