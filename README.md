# TS32
Begleitung des Seminars TS32 "Lärm am Arbeitsplatz"

## Lärmrechner und Messübung

- `laermrechner.html` – Rechner für L<sub>EX,8h</sub> (DIN EN ISO 9612:2025) mit Reiter **Messübung**
- `auswertung.html` – Gruppenvergleich für die Seminarleitung
- `index.html` – leitet zum Lärmrechner weiter (Startseite unter GitHub Pages)

### Ablauf Gruppenübung
1. Gruppe öffnet den Lärmrechner (Link/QR-Code, oder „Rechner herunterladen“), Reiter *Messübung*.
2. Gruppennummer und Namen eintragen, Stichproben je Tätigkeit eingeben (Zeiten sind mit 1 / 2 / 1 / 3 / 1 h vorbelegt).
3. Am Ende **„Ergebnis speichern“** (Datei `gruppe-N.json`) oder **„Ergebnis kopieren“** (Code) und per Mail an die Seminarleitung senden.
4. Seminarleitung öffnet `auswertung.html`, lädt die Dateien bzw. fügt die Codes ein und erhält die Übersicht (Min, Max, Spannweite, Mittelwert, s) für L<sub>Aeq</sub> je Tätigkeit und für L<sub>EX,8h</sub>.
